## 2025-05-15 - Resource leaks in JSON providers and MacKeyRepeat
**Vulnerability:** Resource leaks in several classes (`IjPluginExtensionsScanner`, `IjJsonExtensionProvider`, `CommandProvider`, `ExCommandProvider`, `VimscriptFunctionProvider`, `MacKeyRepeat`) due to `InputStream` and `OutputStream` objects not being closed after use. Additionally, insecure logging via `printStackTrace()` was found in `IjPluginExtensionsScanner`.
**Learning:** `Json.decodeFromStream` and `Json.encodeToStream` from `kotlinx.serialization` do not automatically close the underlying streams. Similarly, streams from `Process.inputStream` need explicit closure. Failing to close these streams can lead to file handle exhaustion. Using `printStackTrace()` can leak sensitive internal details.
**Prevention:** Always wrap `InputStream` and `OutputStream` in `.use { ... }` blocks. Use the project's `VimLogger` via `logger.error("message", exception)` instead of `printStackTrace()` for better error reporting and to avoid information disclosure.
