## 2025-05-15 - Resource leaks in JSON providers
**Vulnerability:** Resource leaks in several JSON provider classes (`IjPluginExtensionsScanner`, `IjJsonExtensionProvider`, `CommandProvider`, `ExCommandProvider`, `VimscriptFunctionProvider`) due to `InputStream` and `OutputStream` objects not being closed after use with `kotlinx.serialization`. Additionally, insecure logging via `printStackTrace()` was found in `IjPluginExtensionsScanner`.
**Learning:** `Json.decodeFromStream` and `Json.encodeToStream` from `kotlinx.serialization` do not automatically close the underlying streams. Failing to close these streams can lead to file handle exhaustion and potential memory leaks. Using `printStackTrace()` can leak sensitive internal details and is not the preferred logging method in this project.
**Prevention:** Always wrap `InputStream` and `OutputStream` in `.use { ... }` blocks when using them with `kotlinx.serialization` or any other stream-based operations. Use the project's `VimLogger` via `logger.error("message", exception)` instead of `printStackTrace()` for better error reporting and to avoid information disclosure.
